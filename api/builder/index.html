builder

This item only works when running on the server. Serverserver-util

The build loop, and the two ways work enters it.

This module only orders and drives work — the pieces live elsewhere: walls makes geometry, prefab reads sources, placement builds one prefab, jobs holds the work item, demolition tears down.

Visibility is not handled here either. A placement's model is built once and handed to its entity; the show and hide systems parent it in and out as Render changes.

Spends the frame's remaining budget across every live job.

Walls come first across all jobs, then prefab detail across all jobs. A chunk with bare walls is navigable; a chunk with props and no walls is a player falling through the world, so walls win the budget every time.

Prefabs are only queued here. The clone system copies them node by node and a placement lands in the world from its own completion callback some frames later — which is also why the queue must be drained by that separate system and not from here, since this function returns early once no jobs remain.

Jobs whose chunk has already been detached are dropped up front, before any budget is spent. The loops below consume from the end of the list, so a dead job sitting earlier would survive every frame the budget ran out on — one was observed lingering for seconds after its chunk unloaded.

Always builds at least one thing per call, so an exhausted budget slows the world filling in rather than freezing it.
