slowClone

shared-util

Clones a hierarchy one node at a time instead of all at once.

Instance:Clone() deep-copies an entire subtree in a single uninterruptible call — a 272-part house is one spike you cannot break up. Instance.fromExisting copies exactly one node and none of its children, which turns the same work into a queue that can be stopped at any point and resumed next frame.

Nothing produced here is parented. A job hands back its detached root immediately and fills it in over subsequent frames, so a half-built clone never costs the engine anything. Use slowParent to stream it into the world afterwards.

Adapted from the feat/better-maze-generation prototype, with the budget changed from a private microsecond allowance to the pipeline's shared frame deadline.

Functions​

enqueue​

</>
slowClone.enqueue(
template: Instance,--

Source hierarchy. Not modified.

onComplete: (Instance) → ()--

Called with the finished root.

) → Instance--

The detached root clone.

Queues a hierarchy to be copied and returns its root immediately.

The returned root is detached and initially childless; it gains its contents over the following frames. onComplete fires once, deferred, when the last node has been copied.

processNext​

</>
slowClone.processNext(
deadline: number--

os.clock() value to stop at.

) → number--

Nodes copied.

Copies nodes until the deadline passes, oldest job first.

Always copies at least one node per call, so a frame that is already over budget still makes progress rather than deadlocking the queue.

clear​

</>
slowClone.clear() → ()

Drops every queued job. Their roots are left detached and unfinished, so the caller is responsible for destroying anything it still holds.
