client

This item only works when running on the client. Clientcore

Client entry point. Starts replication, boots the ECS, mounts the UI, then pulls the initial world snapshot from the server.

The listeners go on before lync.start, which seals what a side has attached; start then waits for the server's remotes to replicate, so everything below it runs on a live connection.

startup is handed the shared systems alone. Applying replication is the only thing the client ever did on a tick, and Lync dispatches that to the listeners below instead, so there are no client-only systems to register.
