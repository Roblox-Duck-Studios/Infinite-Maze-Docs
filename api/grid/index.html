grid

shared-helper

Plain-table maze storage. Holds the shared wall edges and the per-cell records that every generation pass reads and writes, with no buffers or bit masks anywhere — a maze can be printed, diffed and inspected at runtime.

Types​

Cell​

</>
interface Cell {
x: number--

Cell column within the chunk, 0-indexed.

y: number--

Cell row within the chunk, 0-indexed.

wallUp: boolean--

Solid edge on the +Y side.

wallDown: boolean--

Solid edge on the -Y side.

wallLeft: boolean--

Solid edge on the -X side.

wallRight: boolean--

Solid edge on the +X side.

claimed: boolean--

Something has been placed here; no second placement may take it.

captured: boolean--

Inside a room footprint, so the carver must skip it.

reserved: boolean--

Borders a room and is held clear so rooms do not abut.

}

One maze cell.

The three flags are live throughout generation. The four wall booleans are not: they stay false until grid.materialiseWalls copies them down from the edge grids once carving has finished. Read walls off the edge grids during generation, and off the cell afterwards.

Maze​

</>
interface Maze {
size: number--

Cell count along each axis.

cells: {{Cell}}--

Cell records, indexed cells[y][x], both 0-indexed.

horizontal: {{boolean}}--

Edges perpendicular to Y, indexed horizontal[y][x], y in 0..size.

vertical: {{boolean}}--

Edges perpendicular to X, indexed vertical[y][x], x in 0..size.

}

One chunk's maze.

Walls live on the edges between cells, not on the cells themselves, because an edge is shared: cells[y][x].wallUp and cells[y + 1][x].wallDown are the same wall. Storing it once on horizontal/vertical means a carve can never leave the two sides disagreeing.

Side​

</>
type Side = "up" | "down" | "left" | "right"

One of a cell's four edges.

SideEdge​

</>
interface SideEdge {
horizontal: boolean--

True if this side lies on the horizontal edge grid.

dx: number--

Column offset from the cell to its edge.

dy: number--

Row offset from the cell to its edge.

stepX: number--

Column delta to the neighbouring cell across this side.

stepY: number--

Row delta to the neighbouring cell across this side.

}

How to get from a cell to one of its edges, and to the cell beyond it.

materialiseWalls​

</>
grid.materialiseWalls(maze: Maze) → ()

Copies the edge grids down onto every cell's four wall booleans.

Call this once, after all carving and placement has finished. The cell wall fields are a read-only view for consumers; anything that still needs to change a wall must go through grid.setSide before this runs.
