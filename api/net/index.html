net

common

The Lync namespace both sides require, carrying replecs' replication traffic.

Replecs hands out a buffer it packed itself plus a variants list holding every value it could not pack — Instances and CFrames, which no buffer holds. The buffer rides as opaque bytes and each variant crosses on the arm of variantCodec that matches its type, Instances travelling in the sidecar array Lync sends beside every frame.
