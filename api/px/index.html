px

This item only works when running on the client. Clientcommon

Resolution-independent UI sizing. Converts design-space pixels, authored against a 1280x720 reference, into scaled values that hold up across viewports.

Functions​

usePx​

</>
px.usePx() → ()

Binds the shared scale factor to the current camera's viewport.

Call once inside a Vide scope; the connection is cleaned up with that scope. The aspect ratio is clamped at 16:9 so ultrawide viewports scale by height rather than stretching the UI out to the edges.

</>
