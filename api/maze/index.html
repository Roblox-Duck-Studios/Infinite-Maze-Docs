maze

shared-helper

The maze carver. Runs a randomised growing-tree walk over a solid block of cells, then punches the doors that let one chunk connect to the next.

Types​

Direction​

</>
interface Direction {
dx: number--

Column delta to the neighbouring cell.

dy: number--

Row delta to the neighbouring cell.

horizontal: boolean--

True if the edge between them is on the horizontal grid.

edgeX: number--

Column offset from the cell to the shared edge.

edgeY: number--

Row offset from the cell to the shared edge.

}

One of the four steps the carver can take, with the edge it must open to take it.

Functions​

carve​

</>
maze.carve(
maze: Maze,--

A maze whose edges have been filled solid.

random: Random,--

Seeded per chunk, so carving is deterministic.

bias: number?--

Newest-cell bias in 0..1. Defaults to 0.75.

) → ()

Carves a perfect maze into maze, opening edges as it goes. Cells already marked captured — room footprints and their approaches — are left alone.

bias selects between depth-first and Prim-like behaviour: at 1 the walk always extends the newest cell, giving long winding corridors; at 0 it picks a random frontier cell, giving a bushier maze with more junctions.

Opens the shared doorways on all four chunk borders.

Each border is opened from both sides using the same seeded offsets, so two chunks generated independently — possibly frames apart — still agree on where the openings are.
