mesher

shared-helper

Greedy meshing for maze walls. Collapses each unbroken line of solid edges into a single run so one long corridor becomes one part instead of fifty.

Types​

Run​

</>
interface Run {
axis: number--

Either AXIS_HORIZONTAL or AXIS_VERTICAL.

x: number--

Start column of the run.

y: number--

Start row of the run.

length: number--

Length in cells.

}

One merged wall segment, ready to become a single part.

mesh​
