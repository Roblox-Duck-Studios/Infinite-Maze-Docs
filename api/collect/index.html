collect

shared-util

Buffers a Roblox signal so a system can drain the events that fired since its last tick.

Reacting inside a signal callback runs the work outside the scheduler, at an arbitrary point in the frame and outside the profiler's system boundaries. Buffering moves that work back into the system that owns it.

Buffers a signal's firings for later draining.

Arguments are stored flattened in one array rather than as a table per event, with a parallel array of argument counts to slice them back apart. Events fire far more often than they are drained, so this avoids allocating a table per firing. When the buffer empties, both cursors reset to the start so the arrays do not grow without bound.

The caller owns the returned connection and must disconnect it, normally in the system's cleanup function. 

local nextPlayer, connection = collect(Players.PlayerAdded)
-- inside the system:
for player in nextPlayer do
	-- one iteration per firing since the last tick
end
