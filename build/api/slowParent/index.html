slowParent

shared-util

Streams a detached hierarchy into the world one node at a time.

Parenting a large subtree in one assignment makes the engine register every descendant at once — streaming, physics and replication all bill for it in the same frame. This walks the tree instead: before a node is dropped into the live world its own children are detached, so each individual parent write only ever admits one instance.

The mirror of [slowClone]: that one builds a hierarchy out of sight, this one admits it to the world gradually.

Adapted from the feat/better-maze-generation prototype, with two fixes — the per-call node cap was being compared against the microsecond budget rather than its own argument, so it never applied; and the budget is now the pipeline's shared frame deadline.

Functions​

enqueue​

</>
slowParent.enqueue(
subject: Instance,--

Detached hierarchy to admit.

destination: Instance,--

Where the root belongs.

onComplete: (Instance) → ()--

Called once streaming finishes.

) → Instance--

The same subject, now parented but not yet filled.

Queues a hierarchy to be streamed into destination.

The root is parented immediately, but it is emptied first, so this call admits exactly one instance no matter how large the subtree is.

processNext​

</>
slowParent.processNext(
deadline: number,--

os.clock() value to stop at.

maxNodes: number?--

Hard cap on nodes admitted this call. Defaults to 50.

) → number--

Nodes admitted.

Admits nodes until the deadline passes or the per-call cap is reached, oldest job first.

The node cap exists because time is not the only cost here: a burst of parent writes inside one frame is charged by the engine on the following frame regardless of how quickly the writes themselves returned.

Always admits at least one node per call, so an over-budget frame still makes progress rather than leaving hierarchies half-visible forever.

clear​

</>
slowParent.clear() → ()

Drops every queued job. Roots already parented stay where they are, partially filled, so the caller must destroy anything it does not want left behind.
