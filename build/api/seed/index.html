seed

This item only works when running on the server. Serverserver-helper

Deterministic randomness for worldgen. Every chunk's contents are a pure function of the world seed and the chunk's coordinates, so chunks can be generated in any order, unloaded, and regenerated identically.

Nothing here reads the world. The seed is a parameter, which is also what makes these functions testable — feed a fixed seed, get a fixed maze.

Seed for this chunk's Random.

Hashes a chunk's coordinates against the world seed.

The two multipliers are large odd constants — the same ones Knuth-style integer hashes use — chosen so that adjacent chunks, whose coordinates differ by one, land far apart in the output. The final xor-shift mixes the high bits back down, otherwise nearby chunks share low-bit structure and their mazes come out visibly similar.

The rotate between the two coordinate terms is load-bearing. Folding both in with a single bxor puts them at the same bit positions, where negating both coordinates cancels out and (x, y) hashes to the same value as (-x, -y) — a world point-symmetric about the origin, with 16% of chunks in a 121x121 block sharing a maze with their opposite. Rotating between the terms breaks the symmetry: the same sweep collides zero times.
